ムツルぼかしツール — 高精度スキャン版 v3

顔検出を強化
・MediaPipe BlazeFaceの近距離モデルと遠距離モデルを併用します。
・画像全体を検出したあと、640pxと384pxの重なり合うタイルに分割して再検出します。
・タイル分割により、集合写真や遠くに写った小さな顔の見落としを減らす設計です。
・隣接タイルや複数モデルで重複した検出枠は統合します。
・人物全体検出を有効にすると、人物検出も追加で実行します。

使い方
1. index.htmlをChromeまたはEdgeで開きます。
2. 写真を読み込みます。
3. 顔検出をONにして「高精度スキャンして加工」を押します。
4. 必要なら「人物全体も検出」もONにします。
5. 結果を必ず確認し、漏れた範囲は画像上をドラッグして追加します。
6. JPGで保存します。

注意
・AIモデルの初回読み込みにはインターネット接続が必要です。
・高解像度写真や集合写真では処理に時間がかかり、PCのメモリ/性能にも左右されます。
・顔が極端に小さい、横顔、後ろ向き、遮蔽、暗所、強い逆光などでは検出できない場合があります。
・自動検出に100%の保証はありません。個人情報保護用途では保存前に必ず全体を目視確認してください。
・画像編集はブラウザ内で行い、保存形式はJPGです。
