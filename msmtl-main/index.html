MSMTL MAIN VER 1.2 アップデートのお知らせ

MAIN SYSTEM UPDATE　／　VER 1.2

MSMTL MAINをご利用いただきありがとうございます。今回のアップデートでは、各種ツールへのアクセス性を維持しながら、新機能の追加と画面構成の調整を行いました。

主な更新内容

  • 顔ぼかし機能を追加
    画像内の顔・人物を自動検出し、ぼかし処理を適用できる専用ツールを追加しました。
  • ツール一覧を整理
    各ツールの名称と説明を見直し、機能や用途を確認しやすい構成に調整しました。
  • メイン画面の表示を調整
    既存のロゴ・各ツールへのリンクを維持し、画面全体の視認性と統一感を整えました。
  • 更新情報の表示を改善
    ニュースから更新内容の詳細を確認できるようにしました。

既存機能について

Coco Kids、Shouin、画像関連ツール、動画マニュアルへのリンクおよび顔ぼかしツールは、引き続きご利用いただけます。

今後も、日常業務を円滑に進められるよう、操作性と利便性の向上に取り組んでまいります。
